# Question Bank Generator 🎯

A simple Python CLI app that randomly selects a user-defined number of questions from a predefined list.

## 🚀 Features
- Select random questions without repetition
- User input-based selection
- Input validation (handles invalid and out-of-range values)

## 🧠 Concepts Used
- Python lists
- Random module (`random.sample`)
- Conditional statements
- User input handling

## 📦 How It Works
1. A list of questions is predefined in the code.
2. User enters how many questions they want.
3. Program validates input.
4. Random unique questions are displayed.
